# OnlyFries 🍟✨

Welcome to **OnlyFries** — the ultimate shrine to fries. 🍟💛  
This is my full-stack playground where fries reign supreme, the leaderboard never sleeps, and emoji reactions tell it like it is. Built entirely by yours truly with a little JavaScript magic and **Firebase** for all the backend spice.  

---

## What Can You Do Here?  

- 🌟 **Find fries** — from trendy spots to hidden corner gems.  
- 😋 **Rate fries** — emojis, GIFs, and pure opinion energy.  
- 🗺 **Map it out** — see fries near you and zoom into deliciousness.  
- 🏆 **Leaderboard glory** — see who’s winning the ultimate fry battle.  
- 👤 **Profile vibes** — post, react, and feel seen.  

---

## Tech Snack Bar 🍴

- **Frontend + Backend:** 100% JavaScript via Vibe code  
- **Database:** Google Firebase (all the data magic happens here)  
- **Styling:** Tailwind CSS (so it’s pretty AND fast)  
- **Maps:** Finder map view for locating fries IRL  

---

## Repo Crumbs 🍟

- **components/** – Buttons, cards, maps, all the tasty bits  
- **contexts/** – App-wide state and profile juice  
- **hooks/** – Custom hooks to keep forms & interactions smooth  
- **lib/** – Helpers and map logic (finding fries made easy)  
- **pages/** – Finder, Leaderboards, Profile… the main fry hubs  
- **public/assets/** – Backgrounds, images, and all the visual flavor  
- **scripts/** – Behind-the-scenes stuff: profile, logout, leaderboard tweaks  
- **styles/** – Global + component CSS (the aesthetic fries garnish)
